## Decisions

- Docs replaced: old screensaver plan and specs deleted.
- No Supabase, no auth. Netlify adapter installed, no deploy until all phases are done. The display is served from the PC itself for now (`vite preview`, which works with the Netlify adapter's build because the page has no server routes).
- Pins mark municipalities only. Boundary from Natural Earth, coordinates from CGNDB.
- Base map is Web Mercator for radar alignment. GeoMet takes one layer per request, so rain and snow are fetched separately and composited.
- Radar older than 1 hour (by newest frame) is hidden. Label is Toronto time. Radar frames are requested at most 1600 CSS pixels wide.
- Panel: the bottom strip is 7%, with map and panel sharing the width 75 to 20. Rotation is every 20 seconds on a monotonic clock, and clicking a pin holds that municipality for 60 seconds. Weather comes from the nearest Environment Canada site, fetched per site and cached in memory. Census data and nearest sites are generated by `scripts/build-municipality-data.mjs` and committed.
- Panel text uses one unit, `--u = min(1cqw, 0.36cqh)`, so the card fits any screen shape. The tallest card (3 line name, 2 warnings, full forecast) leaves at least 10% spare at eight screen sizes from 1024 by 768 to 3840 by 2160.
- A site's weather is dropped 2 hours after it was fetched. A reading observed more than 2 hours ago loses only the current conditions, since the forecast and warnings are still good (Deep River's station goes quiet for hours).
- The page runs with `ssr = false` (`src/routes/+page.ts`): it needs `window`, and the shuffled order would not match server rendered HTML.
- Status bar: Toronto time without seconds, a derived municipality count, an 8 second ticker, and all credits. Temperatures in the ticker name forecast sites, not municipalities, because the municipalities share a smaller set of sites. Alerts count municipalities and need every site fresh. Your own ticker lines go in `src/lib/data/tickerMessages.ts`.
- Kiosk: the cursor hides after 3 idle seconds; the page reloads itself at 4:00 am Toronto time, and if its map freezes for 2 minutes (at most once every 10 minutes); the app asks for a screen wake lock; `scripts/start-kiosk.ps1` keeps the server and Edge running and `scripts/stop-kiosk.ps1` stops them.
- Agents were copied from `docs/Agents/` to `.claude/agents/`. They load as agent types only in a new session; this session ran them through a general-purpose agent.

## Open questions

- Layout options: five mockups (today, floating card, top billboard, daylight, wide two column panel) are on a private canvas at https://claude.ai/artifact/TrLWv5HPcXMdbmFvKuPxQL. The owner has not picked one yet.
- Credit text has no minimum size, as requested, so it is about 8.6px at 1024 by 768.
- To add a municipality: add it to `municipalities.md` and `src/lib/data/municipalities.ts`, then rerun `scripts/build-municipality-data.mjs` with the Statistics Canada CSV (the link is at the top of the script). The tests that count municipalities need the new total.
- Landmark facts were checked against web sources but should be read by someone who knows the towns. Only ten municipalities have one; more can be added to `src/lib/data/landmarks.ts`. Drive distances come from the OSRM demo server (`scripts/build-office-trips.mjs`, rerun when municipalities change).
- A stale `npm run dev` left running on a lower port can serve old styles; use the port the newest server prints.
- Dawson and Head, Clara, Maria coordinates are the least certain matches.
- Radar colours are GeoMet defaults; tuning to the blue and gold palette is a later pass.
- The highlight label can cover neighbouring pins in the dense Timiskaming cluster. Accepted for now.
- Killarney's station reports no temperature at the moment, so it is left out of the ticker's temperature reading and its municipalities show forecast only.
- Edge's own memory can grow over weeks. A weekly Edge restart was left out; the supervisor script restarts Edge if it dies.
