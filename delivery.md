## Decisions

- Docs replaced: old screensaver plan and specs deleted.
- No Supabase, no auth. Netlify adapter installed, no deploy until all phases are done.
- Pins mark municipalities only. Boundary from Natural Earth, coordinates from CGNDB.
- Base map is Web Mercator for radar alignment. GeoMet takes one layer per request, so rain and snow are fetched separately and composited.
- Radar older than 1 hour (by newest frame) is hidden. Label is Toronto time.
- Panel: layout is a 5% bottom strip, with map and panel sharing the width 75 to 20. Rotation runs on a monotonic clock. Weather comes from the nearest Environment Canada site, fetched per site and cached in memory. Census data and nearest sites are generated by `scripts/build-municipality-data.mjs` and committed.
- A site's weather is dropped 2 hours after it was fetched. A reading observed more than 2 hours ago loses only the current conditions, since the forecast and warnings are still good (Deep River's station goes quiet for hours).
- The page runs with `ssr = false` (`src/routes/+page.ts`): it needs `window`, and the shuffled order would not match server rendered HTML.
- Status bar: Toronto time without seconds, a derived municipality count, an 8 second ticker, and all credits. Temperatures in the ticker name forecast sites, not municipalities, because 50 municipalities share 21 sites. Alerts count municipalities and need all 21 sites fresh. Your own ticker lines go in `src/lib/data/tickerMessages.ts`.
- Agents were copied from `docs/Agents/` to `.claude/agents/`. They load as agent types only in a new session; this session ran them through a general-purpose agent.
