MuniMap is now running on your laptop with no dev server window. I rebuilt it from the latest main, so it includes the moon and the new status bar facts. I then started the existing kiosk script in a hidden window and checked that it answers.

To use it: open http://127.0.0.1:4183 in any browser. This only starts the server, so you get an ordinary browser window and can still use the rest of your laptop. Press F11 for full screen.

To stop it:
powershell -ExecutionPolicy Bypass -File scripts\stop-kiosk.ps1

To start it again later (for example after a reboot), run this from the project folder:
powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File scripts\start-kiosk.ps1 -NoBrowser
You can put that in a shortcut on your desktop. Make the target powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\Users\james\Documents\ClaudeCode\MuniMap\scripts\start-kiosk.ps1" -NoBrowser.

After code changes: stop it, run npm run build, then start it again. Building while it's running breaks the page until you restart it.

Without -NoBrowser, the script opens Edge in full-screen kiosk mode, which is what the display PC will use. That mode takes over the whole screen, so I didn't use it here.

It's still running now, so leave it up or stop it with the command above. I haven't changed any files in the project. If you'd like a one-click desktop shortcut or a "windowed" option on the script, tell me and I'll add it.
